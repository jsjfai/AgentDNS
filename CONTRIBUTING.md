# Contributing to AgentDNS

Thank you for your interest in contributing to AgentDNS.

## Development Setup

```bash
git clone https://github.com/jsjfai/AgentDNS.git
cd AgentDNS
pip install -r requirements.txt
```

## Pull Request Process

1. Fork the repository and create your branch from `main`.
2. If you've added code, add tests where applicable.
3. Ensure the code passes linting: `ruff check .`
4. Update documentation if needed.
5. Open a Pull Request with a clear description of changes.

## Code Style

- Follow PEP 8 conventions.
- Use type hints for function signatures.
- Keep functions small and focused.

## Commit Messages

Follow [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` New feature
- `fix:` Bug fix
- `docs:` Documentation changes
- `chore:` Maintenance tasks
- `refactor:` Code restructuring
- `security:` Security improvements
- `ci:` CI/CD changes

## Branches

- `main` — stable, production-ready code
- Feature branches — `feature/description`
- Fix branches — `fix/description`

## Questions?

Open an issue or contact the maintainers.
